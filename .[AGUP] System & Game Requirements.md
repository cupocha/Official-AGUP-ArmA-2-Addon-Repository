# System Requirements

**Minimum**

- Processor : i5-4670s
- Graphics Card : intel Hd 4000 Graphics or higher
- Ram : 4-6GB DDR3
- Storage : 8 GB HDD free for AGUP
- Game : ArmA 2 Combined Operations (Base+OA)

**Recommended**

- Processor : i5-4670s or higher
- Graphics Card : intel Hd 4600 Graphics or higher
- Ram : 8GB DDR3
- Storage : 9 GB SSD free for AGUP 
- Game : ArmA 2 Combined Operations (Base+OA)

# Additional Note

If your system doesn't meet these requirements it means it can run it yes i mean it.
These system requirements are what i use on my daily PC.
